# LC PLAY para Roku

Aplicativo SceneGraph/BrightScript com ativação no próprio dispositivo. Antes de instalar em uma TV real, ajuste `API_URL` no `manifest` para um endereço acessível pelo Roku e gere os arquivos PNG em `images/`.

O identificador utilizado é `GetChannelClientId()`. O aplicativo não depende do endereço MAC e não inclui conteúdo pré-carregado.
